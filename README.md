# SP-CFAR
Superpixel-driven CFAR algorithms for ship detection in SAR images.


This repository contains source MATLAB code for superpixel-driven CFAR algorithms for ship detection in SAR images, as described below:

O. Pappas, A. Achim and D. Bull, "Superpixel-Level CFAR Detectors for Ship Detection in SAR Imagery," in IEEE Geoscience and Remote Sensing Letters, vol. 15, no. 9, pp. 1397-1401, Sept. 2018, doi: 10.1109/LGRS.2018.2838263.

If you make use of this code please cite the above publication.
